# PinSearch-Scrapper
This is a modular Python scraper that: - Logs into [PinSearch.co](https://app.pinsearch.co) - Navigates to the Keyword Finder tool - Automatically searches and exports all related keywords for a list of seed keywords
pinsearch_scraper/ 
├── main.py # Entry point 
├── login.py # Login logic 
├── loop.py # Keyword search & export logic 
├── config.py # Email, password, and keyword file path 
├── data.txt # List of seed keywords (one per line) 
├── requirements.txt # Required Python packages 
├── README.md # Project documentation
